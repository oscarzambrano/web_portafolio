## Plataforma SAP

### SAP Business Technology Platform (BTP)
- **SAP BTP Cloud Foundry Runtime**: Desarrollo y despliegue de aplicaciones cloud-native
- **SAP HANA Cloud**: Gestión de bases de datos in-memory, modelado de datos
- **SAP Data Sphere**: Arquitectura de datos empresarial, integración de fuentes de datos
- **SAP Analytics Cloud (SAC)**: Desarrollo de dashboards ejecutivos, storytelling con datos
- **SAP Business Application Studio (BAS)**: Desarrollo low-code/no-code

### SAP AI & Machine Learning
- **SAP AI Core**: Entrenamiento y despliegue de modelos de ML en producción
- **SAP AI Launchpad**: Gestión de workflows de IA
- **SAP HANA Vector Engine** (Early Adopter): Procesamiento de embeddings para IA Generativa

### SAP UI/UX
- **SAP Fiori UI5**: Desarrollo de interfaces modernas

## Cloud Computing & DevOps

### Amazon Web Services (AWS)
- **AWS EC2**: Gestión de instancias compute
- **AWS ECR**: Registro de contenedores Docker
- **AWS S3**: Almacenamiento de datos y modelos

### Contenedorización & Orquestación
- **Docker**: Creación de imágenes, dockerización de aplicaciones ML
- **Kubernetes** (básico): Despliegue de contenedores
